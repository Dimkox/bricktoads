# Учёт работ BrickToads

При изменении состояния работы обновляй связанную карточку проекта BT в Jira. При создании, закрытии, повторном открытии и переходе на проверку используй переход Jira и укажи причину и подтверждающий результат. При повторной работе по той же причине верни существующую карточку в работу. Самостоятельный объём работы оформляй отдельной карточкой.

Для событий, внесённых позже, указывай фактическую дату события по Москве и основание в описании или комментарии. При неизвестной дате отмечай это явно. Сохраняй историю предыдущих закрытий. Код, утверждённые материалы и результаты сверок фиксируй в GitHub со ссылкой на ключ Jira. Различай подготовку файла, его публикацию и решение внешней модерации.

# BT-125. Сверка хронологии на 27 ноября 2026 года

Все даты московские. Для BT-1–BT-109 сохранены существующие даты начала. Для пустых полей использована дата открытия карточки в опубликованном журнале. Она включает постановку задачи и подготовку ТЗ. Даты закрытия для этой группы взяты из того же журнала. Для BT-110–BT-120 использованы даты событий в отчёте проекта, для BT-121–BT-124 — материалы отдельных поставок и текущий статус Jira. Четыре ранее заданных срока открытых эпиков сохранены. Прочерк означает отсутствие подтверждённого срока или даты завершения.

## Модели BT-75–BT-107

Внутриигровая проверка охватила 29 семейств, 166 сегментов и 368 поз. Отдельные критерии сдачи 33 UHD-моделей включают исходники, LOD, PBR, клипы и проверку управления. Авторы отчёта явно ограничили объём приёмки. На дату сверки две карточки в работе (BT-82 и BT-90), остальные 31 ожидают выполнения.

## Реализовано

Чистый Combat хранит raw Life, профиль 18/21/22, нелинейную формулу и завершение лёгкой реакции. Session связывает его с прежним RunLifecycle, синхронным появлением и единственным расходом, серверными намерениями, защитами, сохранением отключённого тела и начатой атаки. RobloxWorld содержит новые Humanoid-модели, самостоятельную геометрию, безопасную опору/свободный объём, серверное сетевое владение, импульсы и причины смерти. Клиент содержит камеру, клавиатуру/touch, прыжок, два действия, пять дробно заполненных сердец и состояние возвратов. Сборщик выдаёт отдельный CombatStand.rbxlx.

Реальные игровые тесты не выполнены. Наличие API-вызовов или сборки не подтверждает работоспособность физики, камеры, управления или reconnect в движке.

- 318 проверок Combat — PASS в системной Lua 5.4. Независимые ожидаемые таблицы для damage=4/16 сверены с исходной сохранённой таблицей, 0..47 проверены для всех трёх выбранных параметров повреждения.

- 7 структурных тестов — PASS. Детерминированная XML-сериализация, точное вложение исходников, приватность ядра, отсутствие внешних asset ID, неизменённый blob Core.
- Все Lua-файлы стенда загружены компилятором Lua 5.4 без выполнения Roblox API. Это НЕ проверка типов/доступности Roblox API и НЕ native Luau.

Нативный Luau 0.745 и оба CI workflow оцениваются по конкретному запуску GitHub Actions после публикации, а не по наличию YAML. Сохранённые результаты в этом документе не являются заранее объявленным PASS будущего CI.

## Ревью и пределы результата

Выполнено самостоятельное ревью; независимый агент/внешний ревьюер не запускался. При ревью добавлен сначала падающий тест на сохранение выбранного профиля физического ответа: отсутствие profile в World-границе воспроизведено, затем исправлено. 18/21/22 имеют отдельные явные экспериментальные импульсы. Добавлены проверки rate limit, отказа аварийной замены, порядка одновременных атак и неполных идентификаторов. Журналы red/green сохранены в локальном рабочем пакете; CI повторяет итоговые контракты.

`5 * Life / 47`, геометрия, длительности, хитбоксы и импульсы — инженерные предложения стенда, не утверждённая числовая приёмка BT-33. Обычный щит не получает невыведенный иммунитет к импульсу/фатальной геометрии. Нет полноценного разбега/анимации тарана, всех приёмов первого уровня или точного переноса исходных траекторий.

`reports/stand-source-index.json` — компактный проверенный индекс наблюдений и SHA-256. Он не заменяет полные кадровые трассы, `results/verification.json` и машинную BT-33-transfer.json: они по-прежнему в ранее выданном архиве SHA-256 `57f20f3b49b7d6e3ab828c036b10507905a5bda091cee38a78ea7296b08912bf`. Перенос полного набора данных в Git этим PR не завершён. ROM, ASM, сохранения и оригинальные ресурсы не публикуются.

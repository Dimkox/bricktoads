# Hero presentation implementation

The pure hero sampler now selects decoded source air/apex/held-jump, carry/depth gait, front/rear/stun and heavy reaction graphics, in addition to existing idle/walk/run, accepted attacks and first-boss fear. New immutable accepted action records can play source jab B, club, tongue, pickup, throw, boss-ball throw and named rope/fast clips. It never manufactures action identity from recovery state. Commands remain inert markers and never apply damage or motion.

World integration supplies `visualState`, `verticalSpeed`, optional verified `sourceZSpeedRaw`, `holding`, and optional `reaction={heavy,fromRear,grounded,startedAt,timerRaw}`. `visualAction` uses the existing accepted `attack` shape and identity; a real combat `attack` has precedence. Existing explicit `blocked` reasons remain hard cancellation. Dead, reaction, carried and Dragon link states interrupt stale actions and clear enlarged limbs/fear heads. Ordinary replacement, time rewind and independent-actor protections remain in force.

Swim, ride, rope idle, carried, mounted/captured, club idle and death poses use `namespace='Authored3D'`, no invented source graphics ID, and `frameBasis='Authored3DAdaptation'`. Roblox air velocity uses a declared near-apex threshold rather than claiming a source Z byte conversion. Raw source reaction timers use verified selectors; otherwise the short front/rear-to-stun timing is explicitly authored. All joint angles remain 3D adaptations of decoded silhouettes, not extracted skeleton data. Full special-condition/death FSM traces and remaining morph meshes are still separate work.

Brown chooses `CanonicalPlayerBrown` when available; otherwise it clones only validated canonical P1 anatomy. The fallback applies the approved third-player palette only to its clone. Optional Brown morphs similarly prefer dedicated resources, then validated independent Green clones, without mutating Green/Yellow resources. Dedicated Brown base/morph resources preserve their imported atlas and material rather than receiving another tint. The new detailed Brown GLB is a proper atlas remap, recorded separately in `assets/characters/canonical-hero/brawler-palette-variants.json`.

Observed verification before handoff: 25 pure hero contracts; 14 appearance contracts; source appearance wiring, actual rotated-rest joint transforms, existing limb/fear lifecycle contracts and three new Brown integration contracts; existing world-context checks. New pure tests were first observed failing in seven distinct missing-state/action cases, and Brown first failed with `NO_CHARACTER_RESOURCE`. A dedicated-resource test then caught and corrected an unwanted second Brown tint. These local contracts establish routing and cosmetic transforms, not Studio silhouette acceptance or physics simulation. No Studio, Git or combat-module edits were performed by this worker.

## Folded windup and full-body fear pass

Exact source PNGs `hero-1f.png`, `hero-32.png` and `hero-33.png` were inspected before implementation. Source1F now compresses and thickens the retracted right thigh/calf/foot, bends the knee more tightly and compresses the braced torso before restoring the ordinary body for the extended1E boot. Fear32/33 narrow/compress the torso and extend the arms/lower legs; the frontal33 form is narrower and more elongated than32. All use the existing fifteen segments, with explicit `Authored3DSourceSilhouetteMapping` provenance. These relative scales, offsets and depth are authored adaptations of the observed forms, not an extracted NES skeleton or exact universal pixel-to-stud mapping.

The approved wide-mouth heads retain their exact mesh dimensions, local morph joints and material. Their position follows the reshaped body's native attachment chain. Geometry changes apply only to cosmetic MeshParts and attachments. Every update first restores captured base Size/C0/C1/attachment CFrames, then applies one immutable source-frame profile. Invalid, nonfinite, zero, negative or unknown-part profiles are rejected before any partial write. Interruption, rewind, missing context, detach and actor replacement restore those saved values. Missing context now retains the observed accepted-action identity while canceling playback, preventing a stale folded windup from restarting when context returns.

Final local verification: 26 pure hero contracts, five new source-silhouette geometry/lifecycle contracts using actual imported rest rotations, all earlier appearance/morph/fear/Brown/world-context contracts, and both edited runtime modules compile. The new profile and visible-geometry tests were observed red before implementation; a final missing-context replay test also failed before its lifecycle fix. Native rendered acceptance remains the root worker's Studio task; no new GLB or cast-module change was needed for this pass.

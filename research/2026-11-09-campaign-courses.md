# Original campaign course mechanics

The mode inventory comes from [FULL_GAME_SCOPE](../docs/FULL_GAME_SCOPE.md), which pins `feos-tas/DisAssemble@f1a43b69577246850d136473700a333b3cdfe93f` and distinguishes established source families from unverified natural-play populations. Relevant pinned configuration files are [levels_cfgs1.asm](https://github.com/feos-tas/DisAssemble/blob/f1a43b69577246850d136473700a333b3cdfe93f/Battletoads/data/levels_cfgs1.asm) and [levels_cfgs2.asm](https://github.com/feos-tas/DisAssemble/blob/f1a43b69577246850d136473700a333b3cdfe93f/Battletoads/data/levels_cfgs2.asm). This implementation does not establish exact NES timing, layouts, dynamic population, unknown object identities, or complete animation parity.

All courses, seed alternatives, dimensions, enemy placements, speeds, damage bindings, shield behavior, timers, oxygen, input mappings, physics and finish volumes in `CampaignDefinition`/`CampaignModes` are **original Roblox tuning**. The source maps and ROM resources are not used. The existing first causeway continues to use its own section builder.

The simulation subdivides accepted time into at most 1/60-second steps, uses relative swept expanded boxes for hazards/projectiles, accepts at most 0.5 seconds from one delayed frame, and records discarded time. It never fast-forwards a player through unchecked geometry. Ordinary hazard damage passes through `Session:_hit`; crashes check the existing spawn-shield deadline, while falls and drowning use Session's physical-death path. It never writes health, respawns, actor ownership or life history directly.

Actor ID and attempt changes are distinguished from ordinary movement: only an authorized new attempt receives checkpoint positioning. Running qualification requires actual supported directional speed; a midair run toggle cannot increase the accepted takeoff cap. Offline/recovering actors retain their physical mode but lose stale human steering. The first eligible finisher opens the party's course gate and releases that body; trailing living actors keep their transport/control and continue the course until the actual campaign transition. Finished heroes that die in the boss arena respawn on its supported floor.

Vehicle crashes implement the verified group stop/configuration rewind/speed-clear family in the [scooter source contract](2026-11-08-scooter-source.md), with explicitly authored **0.35-second stop**, **0.55-second rewind**, restart acceleration **110 studs/second squared**, and three-body lane offsets. These durations and Roblox coordinates are not measured NES timings. A collision calls `Session:_die` only for the collided hero; surviving riders are held, their input is cleared, and those same bodies rewind to the shared checkpoint without healing, stock spending or attempt changes. A dead cohort waits for a Session-authorized new attempt; elimination and a lost run never manufacture a retry. Camera snapshots carry a rewind serial and endpoints. Checkpoint configuration time is restored, speed starts at zero, and finite course projectiles are cleared. Active scripted rocket-rat passes expire through the director; only encounter triggers at or after the shared checkpoint become eligible to create a new natural encounter after the riders reach the trigger again. Claiming a role never creates that encounter or a replacement body.

`tests/run_campaign_modes.luau` contains deterministic-course and focused mechanics contracts. A steering/wait/jump driver additionally crosses all four serpent rooms with active spikes for five seeds without repositioning the actor, changing geometry, or writing resources. Adjacent overlapping serpent segments have a 1.5-stud ordinary grounded step budget; static room ledges still require explicit jump input. Rotated tower support is checked at 45 degrees against both visible tips and invisible unrotated corners, using the same inverse yaw as native geometry. The radius-14 tower core stops inward body penetration at radius15.6; outward inputs still leave real support and can cause a fall. Finale seed checks establish a continuous supported arrival-to-arena walking corridor.

The test-only `CourseDrivers`/`PlatformDrivers` also complete Rope, Speeder, Ice, Surf, Jet, Ascent, Tubes, Race, Clinger and Tower for seeds1,41,8125. They read course state for planning but issue only normal move/jump/context-action inputs and advance time. Real Session/Core/Combat own damage, shield expiry and resources; every run retains attempt1 and all three respawns. Ice seed1 finishes at raw Life31; the other29 runs finish at47. The tube pilot opposes actual current using ordinary swim input and waits for a physical crusher opening. No actor positions, health, life counts or course geometry are edited by the pilots. Boarding's ordinary flat-floor movement is provided by the in-memory world boundary; ordinary enemy combat and boss fights are separate acceptance requirements. Jet's receding input planner is only a test fixture and is never included in production runtime. A separate real-Session vehicle test eliminates a third hero, crashes the first, and verifies exactly one paid respawn while the second hero retains its existing actor, attempt, stock and damaged Life through the group rewind. These checks establish their named contracts, not an unprepared full human playthrough, real-device acceptance, visual polish, sound completion or source-perfect transfer.

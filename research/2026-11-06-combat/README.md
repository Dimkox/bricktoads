## Воспроизведение

Нужны Node.js и уже имеющиеся у владельца распакованный исходный пакет `Battletoads_USA_decomposition` и ROM, соответствующие `provenance.json`. Они в репозиторий не включены.

```sh
node reproduce.mjs "/path/to/Battletoads_USA_decomposition" "/path/to/Battletoads_USA.nes" "/path/to/new-results"
```

Выходной каталог должен быть новым или пустым и находиться вне исходного пакета. Для побайтного сравнения сохранённого результата использован Node.js v22.16.0 и закреплённый jsnes 2.1.0. Это подготовленные RAM-сценарии одного эмулятора, не естественное прохождение и не Roblox-тесты.
